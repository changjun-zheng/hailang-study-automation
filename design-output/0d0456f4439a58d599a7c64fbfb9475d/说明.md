# 使用 IDEA 创建 Maven 工程 —— 成绩转换（ConvertScore）

## 一、环境

| 项 | 值 |
|---|---|
| JDK | java version "21.0.8" 2025-07-15 LTS（Oracle Corporation，`D:\develop\Java\jdk-21`） |
| Maven | Apache Maven 3.9.14 |
| 编码 | UTF-8（`project.build.sourceEncoding`） |

## 二、Maven 工程创建过程（评分点 1，70%）

1. IDEA 菜单 `File → New → Project`，左侧模板列表选择 **Maven**；
   勾选 `Create from archetype`，选 `org.apache.maven.archetypes:maven-archetype-quickstart`（生成 `src/main/java` 与 `src/test/java` 两层标准目录），点 `Next`。
2. 依次填 `GroupId = com.example`、`ArtifactId = convert-score`、`Version = 1.0-SNAPSHOT`，
   `Create new Projects in` 选工作目录，点 `Create`；弹窗选 **Open in Current Window**，
   右下角出现 `Importing 'Maven projects'` 进度条，等它把依赖下完（首次会拉 junit-jupiter 到本地仓库 `~/.m2`）。
3. `File → Project Structure → Project`，把 **SDK** 设为 JDK 21、`Language level` 设为 21；
   `Modules → convert-score → Sources` 确认 `src/main/java` 标记为蓝色 `Sources`、`src/test/java` 标记为绿色 `Tests`。
4. 右键 `src/main/java/com/example` → `New → Java Class`，建 `ConvertScore`；
   右键 `src/test/java/com/example` → `New → Java Class`，建 `AppTest`（也可右键类名 → `Generate → Test` 由 IDEA 反向生成）。
5. `pom.xml` 里加入 JUnit5 依赖与 surefire 插件（见本包 `pom.xml`）：
   依赖是 `org.junit.jupiter:junit-jupiter:5.11.4`，`<scope>test</scope>`；
   插件是 `maven-surefire-plugin:3.2.5`（surefire 3.x 才自带 JUnit Platform provider，2.x 需额外引 `junit-platform-surefire-provider`）。
   改完点 `pom.xml` 右上角刷新图标或 `Ctrl+Shift+O` 触发 `Reload Maven Project`。

## 三、代码（评分点：ConvertScore 类 + 测试方法）

- `proj/src/main/java/com/example/ConvertScore.java` —— 百分制转等级制，
  `≥85→A`、`70≤x<85→B`、`60≤x<70→C`、`<60→D`，`score>100 || score<0` 抛 `Exception("输入成绩无效！")`。
- `proj/src/test/java/com/example/AppTest.java` —— JUnit5 `@Test void testConvert()`，取 90 分与 65 分各转一次并打印。
- `proj/src/main/java/com/example/App.java` —— `main` 入口，便于直接 `Run 'App.main()'` 看整条边界。

## 四、运行结果说明（评分点 2，30%）
